# Code of Conduct

CodexAgentTeam is committed to a welcoming, respectful, and harassment-free community.

## Expected behavior

- Be respectful, constructive, and specific.
- Assume good intent while accepting corrections.
- Focus criticism on ideas, code, and observable behavior.
- Respect privacy, local data, credentials, and responsible disclosure boundaries.
- Help make participation accessible to people with different backgrounds and levels of experience.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate intimidation, publishing private information, or sustained disruption are not tolerated in project spaces.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this policy. Report conduct concerns privately to the repository maintainer through the contact options on the maintainer's GitHub profile. Security vulnerabilities must follow [SECURITY.md](./SECURITY.md).

This policy applies to repository discussions, issues, pull requests, reviews, and other spaces where someone represents the project.
